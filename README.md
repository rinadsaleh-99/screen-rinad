# شاشة ريناد

مشروع Android TV مستقل بواجهة عربية كاملة الشاشة. النسخة الأولى تعرض الساعة والتاريخ والطقس ومواقيت الصلاة لمدينة الرياض.

## البناء
يمكن بناء APK عبر GitHub Actions باستخدام ملف `.github/workflows/android.yml` المرفق.
ارفع محتويات هذا المجلد إلى مستودع GitHub، ثم افتح Actions وشغّل Android TV APK build.
\n## الخلفية المتغيرة\nتتبدل معالجة الخلفية تلقائياً حسب وقت الرياض، وتُعدّل الألوان بحسب حالة الطقس الحالية (صحو/غائم/مطر) من Open-Meteo. يتطلب تحديث الطقس اتصالاً بالإنترنت.\n
تم حذف اسم الشاشة وأي علامة تعريفية من الواجهة؛ تظهر عناصر الساعة والطقس ومواقيت الصلاة فقط.
